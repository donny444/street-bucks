# StreetBucks (CafeBucks Extended)

The web application of a POS system comprises of management and operations on many entities such as users, orders, stocks, branches, etc. regarding of cafe franchise business. The application is being developed with the use of technologies covering entire software architecture.

## POS System for Cafe Franchise

- The application includes an RBAC system consisting of staff, manager, and administrator roles.
- Centralized database server supporting transactions from multiple branches.
- Insight dashboard displaying charts of sales information on each branch.
- Recipe stock tracking and management in every branch of the business.
- PostgreSQL database and NestJS HTTP server is being hosted on Docker Engine over a Linux server.
- **Skills:** NestJS, Next.js, PostgreSQL, Prisma, Docker

---

## Scopes of the Project

- 3 roles: staff, manager, administrator.
- Database server that supports the cafe branches.
- Analytical dashboard for each branch sales.
- The software is in the form of web application.
- Staff attendance inspection by manager.
- PDF receipt generation and store the files in server.
- Stock tracking for recipes of menus.
- CRUD operations on menus of the franchise by administrator.
- Business analysis of the franchise by administrator.

---

## Tech Stack

- **Client:** Next.js, Redux, Bootstrap, Chart.js
- **Server:** NestJS, JWT
- **Database:** PostgreSQL, Prisma ORM
- **Deployment, CI/CD:** Docker, Nginx, GitHub Actions
- **Testing:** Jest
- **Data Analysis:** Python, NumPy, Pandas, or any related tools
